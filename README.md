## KamiBantu — Platform Manajemen Kegiatan Relawan

**KamiBantu** adalah platform berbasis web untuk menghubungkan relawan dan penyelenggara kegiatan sosial dalam satu sistem yang transparan, adil, dan terstruktur. Aplikasi ini dirancang untuk memastikan bahwa partisipasi relawan dan kredibilitas penyelenggara dinilai berdasarkan konsistensi dan penyelesaian nyata, bukan sekadar jumlah kegiatan.

### Fitur Utama

* Manajemen kegiatan relawan (buat, kelola, dan selesaikan kegiatan)
* Pendaftaran relawan dengan sistem status partisipasi
* Penyelesaian kegiatan berbasis konfirmasi relawan
* Sistem reputasi otomatis untuk relawan dan penyelenggara
* Aturan penyelesaian kegiatan berbasis tingkat partisipasi (80% rule)
* Tampilan dashboard kegiatan dan profil pengguna
* Kontrol akses berbasis peran (relawan dan penyelenggara)

### Sistem Reputasi

Aplikasi ini menggunakan sistem reputasi berbasis **completion rate** dengan syarat minimum aktivitas (hybrid system). Pendekatan ini memastikan bahwa reputasi mencerminkan konsistensi dan tanggung jawab pengguna, bukan hanya volume aktivitas.

* Relawan dinilai berdasarkan jumlah kegiatan yang diikuti dan diselesaikan
* Penyelenggara dinilai berdasarkan kegiatan yang berhasil diselesaikan
* Tidak ada input rating manual untuk mencegah manipulasi

### Teknologi yang Digunakan

* Laravel (Backend dan Business Logic)
* Blade Template Engine
* MySQL
* Tailwind CSS
* OpenStreetMap (Nominatim) untuk lokasi kegiatan

### Tujuan Pengembangan

KamiBantu dikembangkan sebagai proyek pembelajaran dan kompetisi dengan fokus pada:

* keadilan sistem reputasi,
* transparansi proses partisipasi,
* dan desain arsitektur yang mudah dikembangkan lebih lanjut.
